# CF Wizard 0.8.10

Обновление для Windows x64. Исправляет выбор папки индексов и обработку таймаутов при загрузке XML из Gitea.

## Что изменилось

- Диалог выбора папки индексов открывается поверх мастера и получает фокус. В мастере виден статус ожидания. После подтверждения мастер проверяет индекс в новой папке. Отмена сохраняет прежнюю папку.
- У EXE и окна появился значок CF. Штатная строка заголовка стала тёмной, а дублирующая плашка CF из шапки убрана.
- При таймауте загрузки XML из Gitea мастер один раз повторяет запрос того же пакета. При повторном сбое журнал показывает подробности обоих запросов и число файлов, загруженных за попытку индексации. Во время загрузки мастер показывает прогресс.
- Для правил зависимостей M01–M06 расширили регрессионные проверки состава технической CF. Логика правил в этой версии сохраняется.

## Обновление

Запустите `CF-Wizard-0.8.10.exe` на Windows x64 с Microsoft Edge WebView2 Runtime. Готовые совместимые индексы SQLite V3 можно использовать повторно. [Как выбрать папку индексов и использовать Git-кэш](../user-guide.md#как-использовать-сохранённый-индекс-git).

## Проверки и ограничения

Проверены выбор и отмена папки в Windows, оформление окна, закрытие с журналированием и без него, а также интерфейс WebView2. Стандартный набор Rust прошёл 349 тестов. Повторы при таймауте Gitea покрыты тестами. Полная холодная индексация рабочей ветки и новый прогон выборочного объединения на платформе 1С для этой сборки не выполнялись. [Измерения и совместимость 0.8.9](v0.8.9.md).

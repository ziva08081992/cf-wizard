# CF Wizard 0.8.9

Выпуск для Windows x64 уменьшает расход памяти после предпросмотра и ускоряет работу с индексом и кэшем Git на больших конфигурациях.

- После расчёта мастер освобождает рабочие XML-документы и развёрнутые факты. Для сборки и изменения исключений сохраняются скомпилированный план и компактные данные. При ошибке или отмене повторного расчёта доступен предыдущий план.
- Компактный формат SourceFacts V3 уменьшает размер индекса и объём JSON при чтении. SQLite выполняет полные проверки целостности. Деревья Gitea хранятся в отдельной базе SQLite, общие данные Git переиспользуются между коммитами.
- При закрытии мастер освобождает тяжёлые данные в фоне. После просмотра журнала восстанавливается предыдущий статус операции.
- В переносимый комплект входит `Start-MemoryPreview.cmd`. Он записывает память процесса и обнаруженных потомков, чтобы сопоставить пики с фазами предпросмотра.

## Проверка на удалённом рабочем столе

На рабочей конфигурации с 10 выбранными объектами и 803 заглушками первый предпросмотр занял 41,95 с, повторный в том же процессе — 48,47 с. На втором расчёте рабочий набор мастера достиг 6,41 ГиБ, а частная память наблюдаемой группы — 6,57 ГиБ. За следующие 35 секунд в простое максимумы составили 0,97 ГиБ и 1,28 ГиБ соответственно.

Сборка технической CF заняла 54,88 с. Платформа сохранила CF, загрузила её в проверочную базу и прошла обратную проверку. В измерении сборки рабочий набор мастера достиг 1,05 ГиБ, частная память наблюдаемой группы — 1,40 ГиБ. Замеры выполнены на диагностической сборке с тем же поведением приложения. Результат зависит от конфигурации и объёма выбранных объектов.

На локальном корпусе медианный пик рабочего набора при втором расчёте снизился с 7,97 до 4,05 ГиБ. Проверки подтвердили совпадение состава плана, выходных файлов, настроек объединения и результата обратного чтения.

## Обновление

Распакуйте переносимый комплект и запустите `CF-Wizard-0.8.9.exe`. Для перехода с индекса V2 на компактный V3 нажмите «Обновить индекс». Мастер создаст отдельный файл V3 и сохранит старый индекс. Готовый совместимый индекс V3 можно использовать сразу.

Для приложения требуется Microsoft Edge WebView2 Runtime. Для сборки CF понадобится установленная платформа 1С x64.

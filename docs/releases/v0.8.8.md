# CF Wizard 0.8.8

Вкладка «Заглушки» группирует строки по типу самой заглушки. Объект отображается один раз, даже если он нужен объектам разных типов. Все различные причины остаются в колонке «Требуется для». Ранее название группы определялось типом владельца ссылки: поэтому группа «Общие модули» могла содержать справочники и документы. Состав комплекта и обязательность зависимостей не меняются.

В журнал предпросмотра добавлены события `preview-index-open` и `preview-engine`: время открытия индекса и полный вызов расчёта измеряются отдельно. Событие `dependencies-ready` также содержит внутренние `metrics`. Их `total_ms` имеет более узкую границу и не заменяет время полного вызова. При одновременном сбое операции и записи нового диагностического события сохраняется исходная ошибка операции.

Полный состав файлов объектов Git читается окнами до четырёх объектов. В пределах предпросмотра одновременно выполняется не более четырёх provider tree/file запросов; все работы окна завершаются до последовательного принятия результатов. Общие запросы к одному OID не дублируются, полностью прогретое дерево используется без запуска потоков. Порядок ошибок, отмена, полный inventory и строгие проверки сохранены; SQLite и Session не передаются рабочим потокам. Локальная папка использует прежний последовательный путь.

Устранение всей наблюдавшейся задержки пользовательского примера без повторного реального измерения не заявляется. Формат индекса и версии семантики читателей сохранены; обновление индекса только из-за этой версии не требуется.

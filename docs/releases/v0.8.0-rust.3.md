# CF Wizard 0.8.0-rust.3

Разделены проверки обратной XML-выгрузки после сборки CF.

- Полностью переносимые объекты и остальные XML сравниваются целиком по содержимому, с учётом пространств имён и значимых текстовых данных. BSL сравнивается по байтам.
- Для XML-описания заглушки проверяются тип, имя, UUID, сохранённые идентификаторы типов, обязательные свойства и ссылки, сохранённые дочерние элементы с их содержимым. Проверка включает типы реквизитов и колонки табличных частей.
- Дополнение стандартных полей платформой допускается для заглушки. Оно не ослабляет проверку полностью переносимого объекта, форм, предопределённых элементов или модулей.
- Роли проверки передаются из фактически подготовленного состава пакета, в том числе после исключения необязательных заглушек.
- При ошибке сравнения XML сохраняются исходные `before.xml` и `after.xml` в подпапку `Ошибки` выбранной папки журналов. Путь и причина выводятся в сообщении и журнале. Эти файлы могут содержать данные конфигурации.

Переносимый EXE для Windows x64. Для запуска отдельный Python и установщик не нужны; для сборки CF требуется установленная платформа 1С. Настройки, индекс и журналы остаются совместимыми с предыдущей Rust-версией.

Проверки этой версии: автоматические Rust-тесты, сравнение состава и байтов пакетов с закреплёнными эталонами Python, отрицательные сценарии целостности и диагностики, контроль присланной пары XML, проверка запуска собранного EXE с изолированным профилем. Полную сборку пользовательской конфигурации следует повторить в пилоте: автоматические проверки XML и запуск интерфейса не заменяют её приёмку.

# CF Wizard 0.8.3

Версия программы приведена к единой нумерации: **0.8.3**. В окне «О программе» и журналах используется тот же номер.

Имя переносимого файла для Windows x64: `CF-Wizard-0.8.3.exe`.

Исправлено: очистка поля «Комментарий коммита Git» автоматически снимает отбор по последнему поиску. Отметки объектов, обычный поиск и фильтр «Только выбранные» сохраняются.

Выпуск содержит реализацию предыдущей сборки `0.8.0-rust.3`, включая разделение проверки полных объектов и заглушек и сохранение диагностических XML при ошибке. Порядок подготовки технической CF сохраняется.

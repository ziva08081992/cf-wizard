# CF Wizard 0.8.6 — собственные прикладные читатели и комплект

Прикладной путь source → facts → coordinator → frozen projection/package/merge plan → emission guard заменяет перенесённые readers и формирователь комплекта. Shared XML view сохраняет namespaces, происхождение фрагментов и доказательства входа; формы, статические запросы и литералы используют собственные readers. Старые metadata/forms/query producers и projector остаются offline эталонами совместимости.

Неполная обязательная зависимость блокирует сборку адресной ошибкой. Статически распознанный QueryText отличает mandatory targets от строк, комментариев и динамических упоминаний. Выбор минимального состава принадлежит coordinator; serializer исполняет frozen plan. Full resources сохраняют receiver-priority merge. Пропавшие Language, изменение source proofs и неверные QName отклоняются.

Исправлено узкое legacy-исключение `cfg` в старой сопутствующей форме: отсутствие объявления сохраняется как неподтверждённая подсказка, без выдуманного namespace. Некорректные prefixes/QName в современных XML по-прежнему являются ошибкой. Закреплённые independent fixtures не изменялись. Full readback сравнивает обычные строки буквально; QName aliases нормализуются только в известных QName slots.

Версии контракта: SourceFacts schema 2, rule profile `cf-rules-3`; Metadata `source-v2.3`, Registrars `source-v2.2`, References `source-v2.5`, Forms/Query `source-v2.4`, остальные readers `source-v2.1`. Используется отдельный owned cache; V1 читается ограниченным read-only adapter. Кнопка обновления индекса выполняет semantic refresh явно, без записи из preview.

На checkpoint пройдены 222 Rust-теста, fmt/check/clippy. Before/after harness содержит 12 cohorts, по одному warmup и 9 samples, source/index parity, counters, median/P95 и память процесса. Все 120 парных staging/settings outputs совпали. Общего ускорения не установлено: на малых пакетах проверки увеличивают wall time; число XML parses формы уменьшилось. Детальные данные сохранены в локальном audit, native phase измеряется отдельно.

На отдельно разрешённых 17 новых синтетических ИБ выполнены 8 CF/readback и 4 selective merge на 8.3.27.2214. Native receipt привязан к v4; после адресных исправлений current source/index compiler выдал побайтно те же staging/settings/roles, а текущий строгий verifier перепроверил сохранённые exports и отклонил 10 fault injections. Платформа повторно не запускалась, native timing не переименовывается в измерение новой ревизии. Оба независимых повторных code-review дали PASS, EXE собран и прошёл изолированный UI smoke13checks. [Подробная фактическая проверка и ограничения](../reports/cf-wizard-0.8.6-acceptance.md). Приёмка 0.8.5 остаётся исторической и не переносится на новый binary. Реальные ERP/ДО, другие версии платформы и бизнес-сценарии не проверялись. CFE не поддерживается.

Код не объявляется юридическим clean-room. Нормативные значения и compatibility policies сохраняют происхождение; Datafrog и другие библиотеки остаются внешними. [Provenance](../architecture/provenance.md), [finite profile](../architecture/owned-source-profile.md), [LICENSING](../../LICENSING.md) и [NOTICE](../../NOTICE) разграничивают текущие runtime компоненты, исторические oracle и открытые вопросы прав.

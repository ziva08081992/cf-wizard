# CF Wizard 0.8.0-rust.2-diag.1

Диагностическая сборка для исследования ошибки «Обратная выгрузка отличается». При первом расхождении XML мастер по-прежнему отклоняет сборку и сохраняет два сравниваемых файла:

- `before.xml` — байты подготовленного XML перед сборкой CF;
- `after.xml` — байты XML после обратной выгрузки CF.

Файлы находятся в выбранной папке журналов: `Ошибки/readback-<уникальное имя>/`. Полный путь отображается в сообщении об ошибке и записывается в журнал вместе с исходным именем XML и контрольными суммами. Сохранённая пара остаётся после очистки временного комплекта. Повторные операции получают разные каталоги.

Если сохранение не удалось, сообщение сохраняет исходную причину расхождения и дополнительно сообщает об отказе записи. При ошибке второй записи неполная пара удаляется. При успешном сравнении или расхождении BSL дополнительная XML-диагностика не создаётся.

## Как повторить ошибку

1. Запустите `CF-Wizard-Rust-0.8.0-rust.2-diag.1.exe` и проверьте выбранную папку журналов.
2. Откройте ту же выгрузку или ревизию Git и выберите тот же набор объектов.
3. Выполните предпросмотр и сборку тем же способом и той же платформой 1С.
4. Если ошибка повторилась, откройте каталог по пути из сообщения. Упакуйте `before.xml` и `after.xml` в ZIP и приложите его вместе с журналом этой операции.

Проверки XML/BSL, состава комплекта и неизменности платформы сохранены. Параметры запуска 1С, SQLite и хранение токенов не изменены. Причина исходного расхождения пока не установлена: эта сборка собирает необходимые свидетельства, а повторение пользовательского случая остаётся отдельной проверкой.

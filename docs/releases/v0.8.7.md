# CF Wizard 0.8.7 — подготовка XML-комплекта

Сокращена стоимость повторных Windows metadata queries при сохранении проверок каждого ancestor, reparse points и свежести источника. ExW output guard ограничен абсолютными Disk/VerbatimDisk prefixes с прежним std fallback на любую ошибку. Source raw2/3 shortcut устраняет дублирующий запрос только на абсолютном VerbatimDisk. Нового кэша байтов/атрибутов нет; reader/rule/cache contracts и сторонние версии сохранены.

На синтетической форме в27 соседних парах median source78,90→57,09мс (−27,6%), indexed83,49→64,88мс (−22,3%). Результат относится к preview+materialization со строгими guards; initial/update/open индекса и платформа вне таймера. Первоначальные шумные серии сохранены, общий SLA не заявляется. [Методика и все cohorts](../architecture/package-preparation-benchmark-0.8.7.md), [границы решения](../architecture/package-preparation-performance.md).

226 Rust-тестов, fmt/check/clippy, неизменность10 independent fixture files, byte/plan/reasons/settings/roles parity и текущие10positive/10negative saved-readback controls прошли. Старые native receipts17ИБ относятся к прежнему checkpoint; новых ИБ или вызовов платформы в0.8.7 нет. Это не бизнес-runtime приёмка. [Фактическая приёмка и ограничения](../reports/cf-wizard-0.8.7-acceptance.md).

Иконка EXE/taskbar/Alt+Tab, оформление native title bar и удаление внутреннего CF badge записаны в отдельный будущий UI backlog. В0.8.7 UI не изменён. Публичная публикация, commit/push/MR, archive/sync не выполняются; происхождение и прежние лицензионные ограничения сохранены.

# CF Wizard 0.7.3

- Постоянный Git-индекс готов при прежних XML даже после новой SHA с изменением BSL.
- Изменённые XML дают «Нужно обновить»; обновление выполняется по кнопке только для затронутых файлов и удалений.
- Добавлены явная миграция старой SQLite, sparse-предпросмотр, защита от параллельного обновления и журналы проверки готовности/обновления.
- Поставка: один EXE и портативный ZIP. ZIP распаковывается один раз и запускается быстрее.
- Сокращён состав WebEngine; приложение использует тот же утверждённый HTML/CSS.

114 Python-проверок и 2 Qt/WebEngine-сценария прошли. Состав обоих артефактов сверен с закреплённым snapshot; WebEngine smoke-тесты прошли. Word-инструкция проверена по всем 6 страницам.

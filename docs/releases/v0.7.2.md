# CF Wizard 0.7.2

## Изменения

- В поиске задачи Git добавлен пункт «Указать дни…» и положительное целое число суток. Сохранены последние 90 дней по умолчанию и вся история.
- Gitea и GitHub получают одинаково проверенные since/until для открытой SHA. Неверное число, переполнение и выход за поддерживаемые даты отклоняются до HTTP.
- Последний системный HTML-список периода заменён общим тёмным меню. Сохранено исправление контраста выпадающего списка API в подключении Git.
- Добавлены пользовательская инструкция Markdown/Word и скриншоты. EXE поставляется одним файлом.

## Проверки

103 проверки Python и 2 Qt/WebEngine-сценария прошли. Дополнительно проверены мышь, клавиатура, запросы обоих API, сохранение прежнего отбора при ошибке, блокировка во время поиска, синтаксис JS и git diff. Независимое ревью эффективности алгоритма и обоснованности реализации не обнаружило открытых замечаний. Файлы интерфейса и скомпилированные модули EXE сверены с проверенными исходниками.

Инструкция Word проверена по всем шести страницам Microsoft Word PDF-рендеринга; штатный LibreOffice-рендерер недоступен в этой Windows-среде.

## Границы выпуска

Работа с настоящим приватным репозиторием и перенос CF в конкретную базу получателя остаются пользовательским пилотом. Новая пригодность постоянного Git-индекса по манифесту XML подготовлена как отдельный план и не включена в 0.7.2. Текущая SQLite сохраняется, но другая SHA может потребовать кнопки обновления и полной сверки XML.

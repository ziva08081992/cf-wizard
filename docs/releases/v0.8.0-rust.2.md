# CF Wizard 0.8.0-rust.2

Пилотный переносимый выпуск для Windows x64 от 13 ноября 2026 года. На GitHub опубликован как **CF Wizard 0.8.0**, тег **v0.8**. Версия EXE — **0.8.0-rust.2**.

## Что изменилось

Ветка 0.8 переносит движок, SQLite, Git, хранение токенов, сборку и управление окном на Rust. HTML/CSS/JavaScript отвечают за представление. При работе EXE Python и Qt не используются. Размер текущего файла — 8 111 616 байт, около 7,74 МиБ.

Относительно 0.8.0-rust.1:

- Добавлен лёгкий кэш готовых заглушек внутри одного предпросмотра. Повторное использование допускается только при совпадении влияющих входов; новый предпросмотр получает отдельный кэш.
- На попадании в кэш сохраняются сканирование зависимостей, расчёт причин включения и проверки актуальности исходников. Полные XML-деревья не кэшируются.
- Ускорены свежие файловые проверки Windows с сохранением проверки родителей, ссылок и reparse points до и после чтения.
- Убраны лишние поиски ссылок в защищённых свойствах. Поиск повторяющихся имён членов использует карту позиций с сохранением порядка и последнего значения.
- Формат SQLite, настройки, стратегии Gitea/GitHub и способы сборки через Конфигуратор / ibcmd сохранены.

Постоянный Git-индекс используется при неизменных XML, в том числе при новой SHA коммита с тем же набором XML. При изменениях XML обновление выполняется инкрементально **по кнопке**, а не автоматически при каждом запуске. Это отдельный механизм от кратковременного кэша заглушек rust.2.

## Проверки при подготовке EXE

Ниже приведены результаты подготовки бинарного выпуска, а не повторный запуск всех проверок при обновлении документации.

- Прошли 69 тестов Rust, включая пять тестов реальной Session на использование кэша, изменение входов, short-circuit, поля StubSpec, сканирование, причины включения и изоляцию сессий.
- Состав и полный XML-комплект совпали с эталонами в 16 сценариях и двух режимах индекса.
- Все 64 сравнительных запуска Python / Rust на четырёх наборах объектов в режимах XML / SQLite дали одинаковые результаты. Хеши 1042 отслеженных файлов и общей SQLite не изменились.
- Прошли форматирование, cargo check и строгий Clippy. Готовый EXE прошёл 13 проверок интерфейса и предпросмотра в изолированной папке без Python в PATH.

В повторных замерах с SQLite медиана полного предпросмотра составила **0,904 с** для регистра и **0,920 с** для смешанного набора, по три измерения. Пик рабочего набора измерительного процесса — около **113 МиБ**. Эти значения относятся к конкретным наборам и компьютеру; время других сценариев может отличаться.

Реальная сборка CF с обратной выгрузкой, доступ к личным закрытым Git-репозиториям и объединение в целевой ERP для rust.2 повторно не проверялись. Unit-тесты и сравнение XML не заменяют эти проверки. Выпуск остаётся пилотным.

Для запуска нужны Windows x64 и Microsoft Edge WebView2 Runtime. Для сборки CF требуется установленная платформа 1С x64. Режим «Авто» выбирает Конфигуратор 8.3.27.2214. Поддерживается основная конфигурация CF; расширения CFE исключены.

Обновлённые README и руководство описывают Rust-версию, постоянный индекс, поиск по задаче, предпросмотр без staging и просмотр ошибок. В Word и Markdown включены три реальных снимка изолированного EXE с демонстрационной конфигурацией. Иллюстрированный Word имеет новое имя и не подменяет первоначальную текстовую инструкцию из Assets; опубликованные EXE и SHA256SUMS.txt оставлены без изменения.

Алгоритм технической конфигурации перенесён из [alonehobo/1c-partial-cf](https://github.com/alonehobo/1c-partial-cf). Большое спасибо alonehobo за исходный скрипт.

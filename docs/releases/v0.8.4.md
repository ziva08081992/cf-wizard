# CF Wizard 0.8.4

Исправлен подбор ресурсов технической CF:

- Ссылки на общие картинки в XML табличных документов и явно типизированных значениях Picture разрешаются по URI пространства имён, включая переименованные XML-префиксы.
- Зависимые общие картинки и стили переносятся со всеми файлами своего каталога ресурсов. Они остаются зависимостями; список выбранных пользователем объектов не расширяется.
- Полные ресурсные дескрипторы проходят строгое сравнение XML. Остальные заглушки сохраняют проверку UUID и обязательных элементов.
- У обычных заглушек сохранённые свойства со ссылкой на картинку также обязательны: потеря свойства, ссылки или изменение namespace отклоняются. Равнозначные префиксы и XML entities допускаются; полный контроль всех служебных значений заглушки не включается.
- Обратная выгрузка проверяет каждый ожидаемый файл: BSL и обычные бинарные ресурсы — точно, XML — по существующим правилам, ZIP — по именам и содержимому файлов. Перепаковка ZIP и форматирование его manifest.xml допускаются; потеря или изменение содержимого, повреждение архива и неоднозначные имена отклоняются.
- При ошибке ресурса журнал сохраняет before.bin и after.bin; при отсутствии или недоступности обратного файла — before.bin и after-missing.txt. Диагностика XML before.xml/after.xml сохранена.

Индекс SQLite и контракт сохранённых фактов не изменены. Его создание заново для этой правки не требуется. Ресурсные зависимости рассчитываются при предпросмотре и проверяются перед сборкой.

Проверено на **1С 8.3.27.2214**, пакетный Конфигуратор: отдельные временные базы, собственная синтетическая конфигурация, сборка CF и обратная выгрузка. В контрольном варианте без общей картинки платформа удалила ссылку из MXL, и строгая проверка обнаружила потерю. С полным набором ресурсов, включая путь через движок подбора, обратная выгрузка прошла. Один дескриптор без ресурсов сохраняет ссылку, но не изображение; аналогично стиль без Ext/Style.xml теряет значения оформления.

IBCMD в этом исправлении проверен тестами командного маршрута, отдельный платформенный прогон не выполнялся. Сравнение и выборочное объединение с рабочей конфигурацией остаются действиями разработчика; проверка технической CF не является приёмкой объединения или бизнес-сценариев.

Отдельно остаются: распознавание нестандартного XML-префикса StyleItem и политика переноса зависимых общих форм/макетов. Их поведение в этой версии не расширялось.

Файл Windows x64: `CF-Wizard-0.8.4.exe`. Python и Qt для запуска не требуются; для сборки CF нужна установленная платформа 1С.

## Why

Разработчик знает номер задачи или фрагмент комментария коммита, но не должен вручную переносить названия изменённых объектов из истории в дерево мастера. Поиск по комментарию Git должен показать доступные объекты открытой ревизии Gitea или GitHub для последующей сборки технической CF. Корпоративный формат ключа не является ограничением допустимого ввода.

## What Changes

- В текущем Rust-мастере использовать поле «Комментарий коммита Git»: полный ключ вида TASK-123 искать с точными границами, прочий текст — как буквальный фрагмент без учёта регистра. Принимать печатные символы, внешние пробелы обрезать, внутренние сохранять; запрещать управляющие символы до trim, пустое значение и запрос свыше 256 байт UTF-8 до HTTP. Пример номера задачи оставить подсказкой. По умолчанию проверять последние 90 дней и показывать границу периода. В общем тёмном меню предусмотреть «Последние 90 дней», «Указать дни…» с положительным целым N и «Вся история». Использовать существующий поиск и отмену для Gitea и GitHub.
- Объединить изменённые пути совпавших коммитов в каталоге выгрузки и показать в дереве существующие в открытом снимке объекты. Отдельно показать число путей, которым нельзя сопоставить доступный объект.
- Дать команду «Отметить найденные» и сброс фильтра. Сохранять ручные отметки. Комментарий коммита Git вводится отдельно от комментария к комплекту.
- Зафиксировать границы изменения. Режим локальной папки, настройки авторизации, поиск зависимостей и формат CF продолжают работать по действующим требованиям. Jira, сборка исторической версии и автоматический перенос удалений находятся вне сценария.

## Use Cases

### UC-01: Найти объекты для технической CF по комментарию коммита

Разработчик открывает нужную ветку Gitea/GitHub, вводит ключ задачи или фрагмент комментария и запускает поиск. Мастер показывает число коммитов, файлов и доступных объектов с указанием ветки, SHA и периода. Разработчик проверяет найденные объекты, отмечает их вручную или группой и продолжает обычный предпросмотр.

Связанные требования R1, R2, R3.

## Capabilities

### New Capabilities

- cf-wizard-gitea-task-filter — поиск изменённых объектов XML-выгрузки по ключу задачи или фрагменту комментария в коммитах открытой ревизии Git.

### Modified Capabilities

Нет.

## Impact

Текущая доработка затрагивает Rust GitSource и HTML/JavaScript-интерфейс. Прежний Python/Qt-пилот остаётся исторической реализацией. Переиспользуются стратегии Gitea/GitHub и действующий токен чтения; транспорт, API-права и формат SQLite не меняются. Конфигурации, расширения, BSL и XML-метаданные 1С не изменяются.

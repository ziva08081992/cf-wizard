## Why

Мастер сохраняет SQLite, но новая SHA ветки меняет путь снимка и снимает готовность прежнего индекса даже при одинаковых XML. При обновлении уже переиспользуются скачанные blobs и факты неизменных объектов, однако все описания снова материализуются, читаются и хешируются.

## What Changes

- Сохранять в SQLite полный состав XML-входов и их Git blob SHA, роли и владельцев. Одного Configuration.xml недостаточно: тип реквизита может измениться в XML объекта.
- При открытии ветки проверять индекс чтением. Одинаковые входы, источник, helper и версии означают готовность при новой SHA; изменённые входы дают «Нужно обновить». Обновление остаётся явной кнопкой по выбору пользователя.
- По кнопке обрабатывать добавленные и изменённые XML и удаления, пропуская чтение и хеширование неизменных XML. Старый Git-индекс без манифеста переводить на новый формат явным действием с однократной полной сверкой.
- Согласовать Git-предпросмотр и сборку с выборочно загруженным снимком: проверять текущую SHA, манифест и реально прочитанные файлы. Локальный источник сохраняет прежние проверки файловой системы.
- Записывать результат проверки готовности и обновления в журналы с количеством входов и длительностью.

Границы: один сценарий подготовки существующего Git-источника для CF; Gitea и GitHub. Новые способы авторизации, очистка кэша, полный ZIP, клон, Jira и изменения сборщика partial_cf.py не входят в работу. Произвольный период поиска реализуется отдельным изменением.

## Capabilities

### New Capabilities

- `cf-wizard-git-index-reuse`: совместимость постоянного индекса по полному проверенному составу XML, инкрементальное обновление и согласованный Git-предпросмотр.

### Modified Capabilities

Нет опубликованных main specs. Новый контракт адресно уточняет ограничения R4/R5 активного `add-cf-wizard-gitea-source`: разные SHA разрешены только при одинаковых проверенных входах индекса; файлы предпросмотра и сборки всегда принадлежат открытой SHA. Совместимость Gitea/GitHub из R2 `add-cf-wizard-github-source` сохраняется. Согласование этих формулировок входит в задачи реализации.

## Impact

Python-модули `git_source`, `dependency_index`, `adapters`, `helper_worker`, `application`, `qt_view`, их тесты и справка. Модель входов отделена от UI, HTTP и SQL. Конфигурации и расширения 1С, BSL/XML-исходники, информационные базы и права доступа не изменяются. Статические выводы Full Discovery не являются замером реальной скорости или пользовательской приёмкой.

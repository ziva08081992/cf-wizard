## Эффективность алгоритма — проверено

N — число XML, S — их суммарный размер, M — просмотренные коммиты, C — совпадения, K — элементы изменившихся деревьев.

| Сценарий | Время, память и внешняя работа | Локаторы |
|---|---|---|
| Открытие | Ref/commit и деревья каталога, содержимое только Configuration.xml | git_source.py:184–188; github.py:79–155 |
| Холодный индекс | O(N log N) сортировка + O(S) чтение/hash, helper и SQLite. Пачки до 20, GH дополнительно делит по ожидаемым 2 MiB | git_source.py:146–174; github.py:172–234; dependency_index.py:107–149 |
| Warm/incremental | Переиспользование facts, скачивание отсутствующих blobs; остаются полный локальный hash-проход и копирование SQLite draft, это не O(только изменённые XML) | git_source.py:97–128; dependency_index.py:193–236 |
| Поиск задачи | O(суммарной длины сообщений), около ceil(M/100) страниц. Для C совпадений — tree diff по K с пропуском равных SHA и без чтения файлов; худший случай раскрывает весь изменённый каталог | application.py:146–163; github.py:236–299 |
| Зависимости | Primary key объекта, составной индекс target/file/ordinal для регистраторов, кэши reader | dependency_index.py:19–29,268–305 |

Память: O(N·L + содержимое текущих 20 файлов + кэш деревьев). 2 MiB ограничивает ожидаемую GraphQL-пачку, но files() собирает внешний пакет, включая большие REST blobs; общий пик не равен 2 MiB.

Самостоятельные read-only in-memory проверки ревьюера без ФС/HTTP: 29 000 имён длиной 30/80/150 кириллических символов дают 1450 × 20 нейтральных пачек. Gitea 20 длинных путей разбиты на 5 GET, максимальный query 3817 ≤4500, результаты сохранены. Это расчёт/проверка пакетности, не замер времени и не GraphQL points. Реальные HTTP/SSO/лимиты/время остаются пилотом; полный набор 100 тестов и Qt прогон выполнен реализующим агентом и не выдаётся за собственный прогон ревьюера.

## Обоснованность реализации — проверено

Общий GitTransport/GitFiles имеют потребителей в обеих стратегиях. Отдельные клиенты оправданы различиями ref/tree/batch API; фабрика ограничивает provider до доступа к секрету. Токены/cache разделены, старый Gitea target сохранён. Origin-check и запретredirect нужны против переноса Authorization; secret отсутствует в settings/snapshot. Локаторы: git_api.py:58–81,118–140; git_source.py:41–51; qt_view.py:523–594.

Merkle diff обходит предел стандартного списка commit files. First-parent, initial commit, оба пути rename/delete и Blob.mode сохраняют полноту без patch/ZIP. Входные settings/paths/деревья не мутируются; рабочие коллекции и кэши принадлежат экземплярам. Публикация отделена от вычисления; отказ/отмена сохраняют прежнее состояние. Локаторы: github.py:265–299; application.py:146–163; qt_view.py:474–509,547–565.

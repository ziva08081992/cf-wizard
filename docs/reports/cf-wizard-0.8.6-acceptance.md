# CF Wizard 0.8.6: проверка локального артефакта

Техническая замена C01–C16 завершена в документированном конечном профиле. Регрессия legacy `cfg` исправлена; десять закреплённых независимых fixtures не переписаны, строгие XML-проверки сохранены. Старые producers доступны только для offline compatibility tests. Datafrog и другие внешние библиотеки сохраняются.

- Итоговый QG: `fmt`, `check`, `test`, `clippy` в locked/offline режиме и scoped `diff --check` прошли. **222 теста**: application — 5, domain — 13, infrastructure — 203, desktop — 1.
- Оба независимых code-review дали **PASS** на 98 файлах candidate-v5: fixed `one_c_algorithm_review` с запрошенными Sol 6.1 / ultra и отдельный Astra / max. Actual model/effort независимо не подтверждены и записаны как unknown. Semantic Full Path, эффективность и обоснованность рассмотрены отдельно. Все замечания S/A/P/R исправлены и перепроверены.
- На отдельно разрешённых **17 новых синтетических файловых ИБ** платформы **8.3.27.2214** выполнены восемь CF/readback (type/register/assets/form, Designer и ibcmd) и четыре selective merge. Объединение выполнялось через Designer для CF от обоих backends. Полный Carrier/MoveA сравнен строго; локальные данные Document, связь B и Unrelated сохранены, добавлена только A.
- Реальные native-команды относятся к v4. После исправлений текущий compiler/guards выдал побайтно идентичные staging/settings/roles всех восьми случаев; текущий production verifier принял десять положительных exports и отклонил десять искажений: full Name, stub UUID, missing ZIP, register Name, form QueryText. Оба аудитора признали такой адресный carry-forward достаточным. Новый native-прогон v5 и его timing не заявляются. Первоначальный ошибочный offline ZIP-control log сохранён.
- EXE: Windows AMD64, 9,039 MiB, static CRT. Проверяемые частные пути и корпоративные адреса, импорты Python/Qt/VCRUNTIME/MSVCP не обнаружены. Изолированный target сборки сохранил прежние EXE.
- Изолированный UI/IPC smoke прошёл **13 проверок**. Отдельно визуально проверены загрузка синтетического источника и About 0.8.6. Во время обновления индекса переключатели источника заблокированы; закрытие окна отменило update до публикации. Прежний SQLite cache совпал по SHA. После local→Git старое дерево/план не восстановились; Build без выбора disabled. Тестовые окна закрыты. Native и live Git из GUI не запускались.
- Before/after: 12 cohorts, один warmup и девять samples, 24 raw receipts, 120 совпадающих пар staging/settings. Сохранены фазовые counters/timings, OS peak WorkingSet/CommitCharge и sampled PrivateUsage с шагом 5 мс. Измерена регрессия form-source: **50,23→77,65 мс (~55%)**, form-index: **122,79→235,28 мс (~92%; P95 697,84 мс)**. Proofs добавляют работу, но не объясняют всю вариативность wall time. Ускорение всей цепочки не установлено.
- По вопросу пользователя режимы дополнительно чередовались на одном current measurement EXE и одном входе: median 27 samples — **76,19 мс без индекса и 86,72 мс с индексом**. Все 60 outputs/settings совпали. Обновление индекса измерялось отдельно. Индекс хранит facts, а проверки источника, чтение выдаваемых файлов и guards сохраняются. Первоначальные 235 мс не повторились устойчиво; причина разброса общего этапа materialization не установлена. Подробности — PERFORMANCE.md.
- Source/lock/export manifests, SHA256SUMS, CRC архивов и локальные ссылки проверены при упаковке. Export содержит исходники, документацию, fixtures и найденные сторонние лицензии. Приватные XML, активные индексы, ИБ, logs/cache исключены. Два неизменных legacy SQLite fixtures — явное синтетическое исключение.

Не проверялись реальные ERP/ДО, бизнес-runtime, другие версии платформы, live Git API с пользовательским токеном и пределы работы на больших производственных конфигурациях. C/N/M не означает native-проверку каждой строки профильных таблиц. UI guard probe — синтетическая адресная проверка.

Открытые вопросы прав исторического прототипа и отсутствующего upstream license-text unicode-casefold 0.2.0 сохранены. Conservative inventory 192 пакетов и найденные полные тексты включены. MIT относится к собственному коду. Техническая замена не объявляется юридическим clean-room или полностью собственным стеком; публичная публикация не выполнялась.

Старые EXE, исходники и несвязанные изменения, базы и диагностика сохранены. Existing IB, UpdateDBCfg, COM/хранилище, commit/push/публикация и сон не выполнялись.

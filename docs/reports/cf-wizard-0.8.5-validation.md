# CF Wizard 0.8.5: проверка пилотной сборки

Новое ядро подключено к рабочему расчёту. Дополнительная приёмка закрыла положительный canonical selective merge регистра через оба backend без ослабления XML guard. Исчерпывающая coverage 3.1 остаётся открытой; [дополнение](cf-wizard-0.8.5-acceptance.md).

- Финальный Rust QG: fmt/check/test/clippy, locked/offline; **127 тестов прошли**. Два независимых read-only ревью закрыли адресные замечания на одной финальной ревизии из 65 файлов.
- Чистое ядро: **57 точных совпадений** состава/причин, **53 независимых oracle**; отдельно один прогрев и девять модельных измерений каждого случая.
- Продуктовые/legacy fixtures: local/Git/index, stale/source guards, roles, binary/ZIP и исключения. Старый oracle 0.7.3 не переписывался; intentional deltas отделены.
- Реальная 1С **8.3.27.2214 x64**: шесть CF/readback конвейеров — ресурсы, документ как тип, регистратор, каждый через Конфигуратор и ibcmd. Финальное staging/settings побайтово совпало с шестью сохранёнными контрольными случаями, роли проверены; повторные команды 1С не запускались.
- Отрицательные контроли full XML, UUID и ресурса отвергнуты. Для ресурса первоначальная контрольная утилита ошиблась путём ZIP; исправленная офлайн-проверка сначала приняла здоровую сохранённую выгрузку, затем отвергла удалённый ZIP. Это не дополнительный native-прогон.
- Нестандартное свойство ibcmd принял и удалил; отказ вызвал readback guard. Командная ошибка 42 отдельно имитирована Runner: журнал/receipt сохранены, публикации нет, реальных процессов/баз — ноль.
- Selective merge документа как типа прошёл контроль. Для регистра 1С добавила пять StandardAttributes, отсутствующих во входящем полном XML: строгий full-критерий **не принят**. UUID, прочее содержимое документа с локальным маркером, старая связь и несвязанный объект сохранены. Сравнение полного XML не ослаблено.
- EXE: AMD64, статический CRT; импорты Python/Qt/VCRUNTIME/MSVCP и проверенные частные маркеры отсутствуют. UI smoke на отдельном синтетическом профиле прошёл 13 проверок. Дополнительно наблюдались смена источника и отмена preview через закрытие окна, журнал подтвердил отмену без CF. Return-to-idle GUI не подтверждён; живые Git API с пользовательским токеном не проверялись.
- Сравнительные замеры имеют один прогрев и девять измерений. Общего ускорения на маленьких примерах не подтверждено; полная ERP-выгрузка и cold startup отдельно не измерялись.
- Схема SQLite v1 сохранена; для нового preview-драйвера проверена неизменность байтов индекса. Покрытие каждого частного сочетания всех таблиц metadata-политик не заявляется исчерпывающим.

Исходные корпоративные BSL/XML, существующие базы, хранилище и пользовательские токены не изменялись. Использованы 17 первоначальных и 5 дополнительно отдельно разрешённых новых disposable баз; UpdateDBCfg и бизнес/runtime-приёмка не выполнялись. Commit/push/PR/публикация и сон не выполнялись.

## Происхождение

Новый вычислитель собственный, поверх Datafrog 2.0.1. Перенесённые части читателей, XML-проекции и настроек объединения ещё присутствуют. Вариант их собственной замены исследован отдельно; в этом EXE такая замена не заявляется выполненной. MIT относится к собственному коду. Сохранены уведомления и открытые вопросы прав старого прототипа и текста unicode-casefold.

# Замеры CF Wizard 0.9.0

Рабочий ПК с процессором AMD Ryzen 9 7900X и 63,14 ГиБ физической памяти по данным Windows. Для локальных замеров использованы выгрузка ERP УХ, готовый индекс SQLite V3 и Конфигуратор 8.3.27.2214. Замеры проведены 21 ноября 2026 года.

## Размер исходных данных

| Набор | Файлы | Размер |
| --- | ---: | ---: |
| Весь локальный каталог выгрузки ERP УХ | 154 198 | 12 460 695 393 Б |
| Локальные файлы и ресурсы без вложенного готового CF | 154 197 | 10 806 060 048 Б |
| XML в описи для локального индекса, включая `Configuration.xml` | 28 308 | 334 005 855 Б |
| XML в описи для индекса отдельного снимка Gitea, включая `Configuration.xml` | 28 900 | 341 751 564 Б |

Размер каталога показывает масштаб выгрузки на диске. Для конкретного комплекта мастер выбирает исходники по составу объектов и зависимостей. Объём XML в описи индекса приведён отдельно от форм, BSL и ресурсов.

## Предпросмотр и сборка по бюджету

| Рабочий бюджет мастера | Предпросмотр, два прогона | Пик частной памяти мастера при предпросмотре | Сборка CF с обратной проверкой |
| --- | ---: | ---: | ---: |
| 1024 МиБ | 15,1–15,3 с | 862–1096 МиБ | 20,4 с |
| 2048 МиБ | 15,0–15,2 с | 1335–1338 МиБ | 19,9 с |
| 4096 МиБ | 15,2–15,8 с | 2113–2164 МиБ | 20,5 с |

Предпросмотр замерен на 10 объектах с 936 заглушками. Сборка на актуальном EXE замерена отдельно для каждого бюджета на 10 объектах с 790 заглушками. Все три результата прошли обратную проверку, а настройки объединения совпали по SHA-256.

Пик частной памяти относится к процессу мастера. При бюджете 1024 МиБ повторный предпросмотр достиг 1096 МиБ частной памяти и 1306 МиБ рабочего набора мастера. Сам бюджет регулирует кэш и размер порций. Windows, WebView2 и Конфигуратор потребляют память отдельно.

## Сборка до и после ускорения проверки XML

По два прогона с обеих сторон, бюджет 2048 МиБ, 10 объектов, 790 заглушек, 1026 файлов во временном комплекте. Полное время измерено от нажатия **Собрать CF** до завершения обратной проверки.

| Показатель | До доработки | После доработки |
| --- | ---: | ---: |
| Полная сборка, оба замера | 21,44 и 21,98 с | 19,22 и 19,95 с |
| Время до записи CF по журналу | 14,32–14,77 с | 14,04–14,30 с |
| Пик частной памяти мастера | 722–744 МиБ | 729–746 МиБ |
| Пик рабочего набора мастера | 694–698 МиБ | 697–710 МиБ |
| Пик частной памяти процесса Конфигуратора | около 142 МиБ | около 142 МиБ |

Среднее время полного цикла сократилось на 2,12 с, или около 10%. Выигрыш получен при сравнении обратной XML-выгрузки. Во всех прогонах совпали состав, число файлов и SHA-256 настроек объединения.

## Индексация Gitea

Опись обязательных для индекса XML зафиксирована для одного снимка ERP УХ. Она содержит 28 899 XML-описаний на 339 028 952 Б и `Configuration.xml` на 2 722 612 Б.

Для первой индексации большой конфигурации рекомендуем открыть XML-выгрузку в режиме **Локальная папка**, создать индекс и выполнять предпросмотр и сборку из неё. Для прямой работы с веткой можно воспользоваться [готовым совместимым индексом Git](../user-guide.md#как-использовать-сохранённый-индекс-git).

В завершённом прогоне с подготовленным Git-кэшем мастер получил 488 недостающих XML на 36 374 586 Б полезного содержимого. Чтение полного набора заняло 123 с, индекс SQLite был готов через 342 с. Размер готового SQLite составил 274 137 088 Б. Этот результат относится к конкретному набору уже сохранённых файлов.

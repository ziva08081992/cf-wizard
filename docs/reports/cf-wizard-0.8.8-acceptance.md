# CF Wizard 0.8.8: проверки

Область изменения: отображение групп заглушек, измерение времени открытия индекса и полного предпросмотра, ограниченное получение полного Git inventory. Семантика формирования XML, frozen plans, проверки источника, native-команды, семантика читателей и формат SQLite не изменены.

Адресная регрессия воспроизведена по структуре плана: группа должна определяться ключом заглушки, а причины могут относиться к объектам других типов. Тесты проверяют единственную строку каждой заглушки, сохранение всех различных владельцев и пустого списка причин. Ещё два теста проверяют приоритет исходной ошибки и ошибку журнала после успешной операции.

Итоговый Rust workspace 0.8.8 locked/offline: 235 тестов (application 5, domain 13, infrastructure 212, desktop 5), 0 ошибок; fmt/check/clippy PASS. Десять независимых fixture files сохранены без регенерации: Git content не изменён, текущие Windows checkout bytes также зафиксированы. Сторонние пакеты Cargo.lock не менялись; номер 0.8.8 получили только четыре локальных пакета.

Независимые алгоритмический и Astra review дали PASS на точные SHA пяти performance-файлов; freeze-manifest SHA256 `4dcf3626ffe60bbeb34ed551defe32882473381c3dfc47c3e14c50e2a067b379`.

# Приёмка CF Wizard 0.8.5: дополнение

**Положительный T25 на каноническом источнике закрыт.** Программа, строгий XML-компаратор и настройки объединения не изменялись.

Входящие шесть XML взяты без изменений из сохранённой выгрузки самой 1С 8.3.27.2214. Предпросмотр/материализация с SQLite и без него сохраняют полный MoveA побайтово. Через Конфигуратор и ibcmd выполнены CF/readback; затем два новых получателя прошли выборочное объединение.

Полный MoveA сравнивается напрямую с каноническим входящим XML через `verify_xml(..., None)`: StandardAttributes не удаляются и не игнорируются. ProbeDoc сохраняет локальный маркер и MoveB, получает только необходимую MoveA. Его остальное содержимое, Unrelated и сам MoveB сохранены. Исходный sparse-пример без StandardAttributes остаётся отрицательным контролем строгого сравнения.

GUI: смена источника сбрасывает выбор и предыдущий план, блокирует сборку и предлагает папку отдельного индекса. Отмена preview через закрытие окна зафиксирована в активном расчёте: показан запрос отмены, журнал содержит «Операция отменена», успешный комплект отсутствует. Возврат GUI в idle после отмены не подтверждён и не заявляется.

Независимый адресный аудит Astra/max подтвердил корректность этих свидетельств. Фактический backend model ID инструментом не раскрыт. Аудитор не повторял native/GUI-команды.

Бинарный EXE 0.8.5 и исходники реализации не менялись. Ранее выполненные 127 Rust-тестов, fmt/check/clippy, 57 kernel controls и code reviews относятся к тем же хешам. Старый пилотный пакет сохранён как историческая поставка; это дополнение актуализирует её приёмку.

Исчерпывающее построчное покрытие всех таблиц правил 3.1 пока не закрыто; соседний Datafrog change автоматически не архивируется. Оно учитывается при переходе к отдельно утверждённому change `replace-cf-wizard-readers-and-projection`. UpdateDBCfg, бизнес-приёмка, существующие рабочие базы, хранилище и публикация не входят в этот результат. Размеры баз не выводятся по просьбе пользователя.

# Rust / WebView2: тест запуска оболочки

Прототип загружает тот же HTML/CSS-макет мастера через Wry 0.57.2 и системный WebView2. Проверяет native PageLoadFinished, DOM, 39 кнопок и вычисленный цвет фона. Бизнес-логика мастера, авторизация, SQLite и сборка CF в прототип не переносились. Нужен установленный WebView2 Runtime.

Исходные CSS/JS встроены в ui.html, CSP закрепляет их SHA256. Локальный протокол cfprobe обслуживается из памяти; внешняя навигация отклоняется. IPC Qt в этом прототипе не используется. Wry — компонент экосистемы Tauri; полный Tauri здесь не собирался.

Сборка: `cargo build --release --locked`. Запуск EXE требует два аргумента: абсолютный путь нового JSON-отчёта и отдельную папку профиля WebView2. Родительская папка отчёта должна существовать. После подтверждения готовности процесс завершается сам; без профиля и отчёта это не пользовательская программа.

Результаты и ограничения сравнения: [исторический отчёт 0.7.3](https://github.com/ziva08081992/cf-wizard/blob/7c1698cf5b90f1a9ce63a65820070fb0c3c240da/docs/performance-0.7.3.md). Не копируйте target или cargo-home в репозиторий.

Журнал работы

Как собрать техническую CF

  1. Мастер открывает сохранённую выгрузку при запуске. Путь к локальной папке или Configuration.xml можно выбрать в Настройках. Для открытия по введённому пути нажмите Открыть выгрузку.
  2. Для Gitea или GitHub выберите Git. В окне Настройки → Подключение Git выберите API сервиса и введите персональный токен на чтение. Для GitHub.com используйте PAT только нужного репозитория с Contents: Read-only. Выберите ветку и откройте её. Мастер принимает XML-выгрузку основной конфигурации для сборки CF.
  3. Чтобы отобрать объекты по задаче, введите Номер задачи Git, выберите период и нажмите Найти. По умолчанию проверяются последние 90 дней. Для своего интервала выберите Указать дни… и введите целое число больше нуля; Вся история снимает ограничение дат. Отметить найденные добавляет найденные объекты к уже отмеченным. Комплект использует состояние объектов в открытой ревизии ветки.
  4. GitHub загружает XML для индекса пакетами, без полного архива репозитория. Отбор задачи учитывает полный список путей; merge сравнивается с первым родителем. Токены Gitea и GitHub хранятся раздельно.
  5. Подготовьте отдельный индекс ветки кнопкой Создать индекс. Мастер получает XML-описания и затем запрашивает файлы выбранных объектов по мере работы. При смене источника можно выбрать папку SQLite. Интервал проверки SHA задаётся в настройках подключения Git. Значение 0 выключает проверку.
  6. В необязательное поле можно вписать номер задачи, дату или комментарий. Мастер использует текст в имени папки комплекта и заменяет недопустимые символы.
  7. Для ускорения поиска зависимостей нажмите Создать индекс. У каждой XML-выгрузки свой файл SQLite. После обновления выгрузки нажмите Обновить индекс. Мастер пересчитывает записи изменившихся объектов.
  8. Отметьте нужные объекты. Фильтр Только выбранные покажет все отмеченные объекты с учётом поиска. Нажмите Предпросмотр, чтобы увидеть зависимости и заглушки.
  9. На вкладке Заглушки раскройте нужную группу, чтобы увидеть объекты и причины включения. Снять флажок можно, если сборщик нашёл ссылки на заглушку только в комментариях BSL. Обязательные заглушки отмечены словом «обяз.».
  10. В Настройках укажите папку результата и способ сборки. В режиме Авто мастер выбирает Конфигуратор версии 8.3.27.2214. Для ручного выбора укажите ibcmd или Конфигуратор и соответствующий ibcmd.exe или 1cv8.exe из папки bin установленной 1С.
  11. Нажмите Собрать CF. Мастер подготовит XML и проверит CF обратной выгрузкой. Кнопка Открыть комплект откроет папку с CF и настройками объединения. Если поле задачи пустое, папка именуется по дате и времени.

Git-индекс сохраняется между запусками. При прежних XML он готов и после смены SHA. Если XML изменились, мастер покажет «Нужно обновить»: обновление выполняется по кнопке только для изменившихся входов. Старому индексу потребуется однократная полная проверка. Прежний предпросмотр другой ревизии сбрасывается.

Кнопка Открыть журнал показывает журнал последней операции в отдельном окне мастера. Журнал доступен после создания или обновления индекса, предпросмотра и сборки. Кнопка Папка журналов над деревом открывает каталог всех журналов.

Если мастер показал ошибку или закрылся во время работы, откройте подпапку Ошибки и найдите файл по дате и времени запуска.
